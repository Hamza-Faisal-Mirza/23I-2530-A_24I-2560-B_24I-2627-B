Common choices. Crate profiles: food 4-20 kg/value 10-55, water 6-20/15-65, medicine 1-8/40-100, tools 3-18/25-85, rare 1-12/60-100. Capacity is 20-50% of total weight, so it always binds. Road minutes are proportional to geometric length plus noise, and cable is 0.8-2.2x the minutes (terrain). Pipeline dimensions mix narrow 2-10 (25%), 10-60 and 60-100 stages so that the bracketing matters. Drum prices are about unit x j with premium "standard" lengths, saturating below 500. Sites are 80% Gaussian village clusters, so close pairs exist. Ration values are 5-300 (S) or 100-1000. Sensor cover size k is drawn from [n/4, n/2].

## 2. Planted objects and claims (correct by construction)

- **Tour.** Nearest-neighbour tour from site 0 (ties go to the smaller site_no), then deterministic best-improvement 2-opt with site 0 fixed. 2-opt never lengthens a tour, so the planted tour is never longer than the NN tour. On L/X it is 6-17% shorter, so it also beats NN under any tie rule. tour_length is measured from the stored tour.
- **Sensor cover.** The cover C (k nodes) is drawn first. Every edge joins a non-cover node to C, or joins two nodes of C, so C touches every edge by construction. We add edges until there are at least n-1.
- **Safety assignment.** The 0/1 assignment is drawn first. Then we draw random rules over three distinct switches and keep a rule only if the assignment satisfies it (duplicates are rejected).
- **Rations.** The planted subset (2..q/2 items) is drawn first, and rations_target is set to its sum.
- **Radio.** Pattern counts are computed on the joined log with overlaps. An "occurring" pattern is copied from the log. A "missing" pattern is a one-symbol mutation of a log substring, checked to occur 0 times. edit_bound is the exact Levenshtein distance (DP), so it lies between the true distance and len(a)+len(b).
- **Claims (tier S).** The generator uses exhaustive search: knapsack over all 2^n subsets (meet-in-the-middle enumeration), all compatible window subsets by DFS, all integer partitions of L for the drum, all (n-1)!/2 tours, and covers tried by increasing size. The validator recomputes every claim with a different exact method: O(nW) DP, earliest-finish greedy plus weighted-interval DP, O(L^2) rod DP, Held-Karp, and branch-and-bound vertex cover. The two agree on all 20 tier-S cases.
- **Variety.** Variety 1: tier-S cases with k mod 3 != 2 are redrawn until ratio-greedy is not optimal (14 forced, 15 hold). Every tier-S crate list has distinct value/kg, so the greedy order is unambiguous. Variety 2: tier-S cases of studies 1, 3, 4 and 6 are redrawn until some S/H location's fewest-roads routes all cost more than its cheapest route, and that location becomes target_0 (13 forced, 15 hold). Variety 3: a seeded shuffle gives the 26 M/L cases 7 / 12 / 7 rule ratios in [2.6, 3.3] / [3.7, 4.6] / [5.0, 5.9]. Variety 4: serials come from a per-case block of 1.8M numbers, so they are distinct across the workbook. Each draw that breaks a rule is rejected and redrawn with attempt+1, so the result stays deterministic.

## 4. What will be hard

<!-- widths: 0.13,0.87 -->
| Case study | Hardest decisions and the data property behind each |
|---|---|
| 1 Delta Flood | **B route.** Step cost minutes + penalty(v) is asymmetric, 43-55% of locations carry penalty >= 2, and 3-5 waves remove exactly the low-lying roads, so the fewest-roads route is often dearer (76-00, 76-12, 76-18). **A load.** Heavy, cheap food/water with near-equal value/kg; greedy is suboptimal (e.g. 473 vs 483 in 76-00). |
| 2 Earthquake | **D queue.** Mean priority about 8 with urgent bursts, so many alarms tie at priority 9-10; tie order (tick, then alarm_id) must be stable. **F cable.** 2E/V of only 2.1-2.5 and closures split the network: the MST must cover only the HQ's component (a spanning forest otherwise). |
| 3 Cyclone | **C windows.** 5-75-minute windows overlap 3-171 others on average and many touch (finish = start), so `<` vs `<=` changes the answer; value maximisation needs DP, not greedy. **E radio.** 37-38 near-uniform symbols leave Huffman little to gain (4.6-4.9 bits per symbol vs 6 for a fixed code), and pattern search runs through noise. |
| 4 Urban | **D queue.** 1.56-1.73 alarms arrive per tick but one is released, so the backlog peaks at 0.36-0.47n (861 alarms in 76-45); a linear scan becomes O(n^2). **B route.** Dense graphs (2E/V up to 5.1, degree up to 14) with many equal-cost alternatives; the heap holds up to 2E entries. |
| 5 Landslide | **B reach.** Waves cut target_0 off, so "no route" must be reported; corridors up to 356 roads deep (291 in trap 46) strain recursive search. **F cable.** The MST must span only the locations still reachable after the collapse, not all V. |
| 6 Outbreak | **A load.** 65-79% of crates spoil by hour 300, so "the values of the day" change, and value/kg misleads (trap 47 at 55%). **E radio.** The log is skewed (filler 31-44%), so Huffman gives a 1-2 bit code to the filler, and beacons produce many overlapping occurrences. |

For module H across all studies: rule ratios near 4.26 (the 3.7-4.6 bucket) are the hardest region for DPLL, and L-size tours (200-320 sites) and covers (k up to 65) are far beyond exact search. There we will report heuristic answers with bounds against the planted objects.
